## F. 7-DAY CONCIERGE TRIAL

### Trial Design

**Giorno 0 — Onboarding (15 min)**

Customer provides:
- Company sector (dropdown)
- Geography (regioni multi-select)
- CPV codes or services (autocomplete)
- Preferred tender size (range slider)
- Exclusions (optional keywords)

**Giorno 1-7 — Monitoring (5 min/day)**

System:
- Runs TED pipeline daily
- Filters by customer profile
- Sends email alert for high-priority (score > 60)
- Generates weekly summary report

**Giorno 7 — Evaluation (10 min)**

Customer receives:
- Summary of opportunities found
- Feedback form (1-5 scale)
- Offer to continue (Starter/Professional/Enterprise)

### Onboarding Questionnaire

1. **Settore principale** (dropdown)
   - Costruzioni edili
   - IT services
   - Facility/Cleaning
   - Altro

2. **Regioni di interesse** (multi-select)
   - Tutte le regioni
   - Lombardia, Lazio, Campania, etc.

3. **Servizi/Prodotti** (autocomplete)
   - Software development
   - Edilizia
   - Pulizie
   - etc.

4. **Dimensione tipica bandi** (range)
   - Min: €10K / €50K / €100K / €500K
   - Max: €100K / €500K / €1M / €5M

5. **Esclusioni** (optional)
   - Keywords to exclude
